# Crisp Game Studio 🎮

A local-first, offline-capable indie game development workshop and project management toolkit. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **GDD & Milestone Checklist:** Plan and track game mechanics, coding tasks, and development milestones with persistent local storage.
- **FPS to Milliseconds Converter:** Real-time game math tool to calculate frame duration budgets (e.g., 60 FPS = 16.67ms).
- **Tilemap Memory Estimator:** Calculate grid sizes and estimated array memory usage for 2D levels.
- **Asset & Sprite Tracker:** Register and organize sprite sheets, audio clips, and scripts offline.
- **Gaming Dark & Light Themes:** Ergonomic high-contrast themes optimized for late-night coding sessions.
- **100% Offline & Private:** Runs entirely client-side in your browser with zero login walls or external server tracking.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, game math calculators, asset tracking, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
